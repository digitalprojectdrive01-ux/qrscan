How to connect (near-live, refreshable):
1. Replace YOUR_TOKEN with the value you set for PBI_TOKEN in Vercel.
2. Power BI Desktop → Get Data → Web → paste the JSON URL → Anonymous access.
3. Expand the list to a table, set data types, Close & Apply.
4. Publish, then set a Scheduled refresh (e.g. every 30 min) for live updates.
The feed returns every user's records (service-role, server-side). Keep the token private and rotate it if leaked.
Records are stored in your Supabase project, protected by row-level security. Camera and sound need the deployed HTTPS URL; embedded previews may block them.
